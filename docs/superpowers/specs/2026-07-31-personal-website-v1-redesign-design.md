# 个人网站 V1 大更新设计说明

## 目标

把网站从“AI 数据训练实习候选人的网页简历”改造成“小狼 wolfan 的个人作品”。面试官在 30 秒内首先感受到设计美感、创造力、想象力和执行力，随后再通过真实作品、实习经历、简历与联系方式确认专业可信度。

网站本身是 Vibe Coding 能力的第一件证据，不通过堆砌 SFT、RAG、评测等术语证明能力。

## 核心原则

- 完整大于完美：先上线从 Hero 到联系方式都完整可用的 V1。
- 真实大于包装：只展示已确认的项目、实习和数据，不虚构训练或评测经历。
- 作品优先：页面主线为“我是谁 → 我做过什么 → 我如何工作 → 真实经历 → 联系我”。
- AIGC 融入网站视觉，不单独作为作品卡。
- 保留现有黄昏与夜晚背景及日夜切换。
- 静态 HTML、CSS、JavaScript 继续作为技术基础，不引入框架和非必要依赖。
- 所有 Hero 大字与独立短句不加句号。

## 动效与后续扩展

### V1

不安装动效库。使用原生 CSS 与 JavaScript 完成：

- 黄昏与夜晚交叉淡入
- Hero 文案分层出现
- 作品窗口进入视口时错落浮现
- 桌面端窗口画面轻微推进与操作反馈
- 移动端不依赖 Hover
- `prefers-reduced-motion` 下关闭非必要动画

每个作品窗口都使用固定比例的媒体容器，支持静态图片、原生 `<video>` 和未来视频封面，避免后续为了加入动效重构卡片。

### 后续动效库决策

- 只有在需要滚动时间线、连续转场、复杂编排时才引入第三方库。
- 优先候选为 GSAP 与 ScrollTrigger，但在明确镜头脚本和性能预算后再决定。
- 普通淡入、位移和 Hover 仍使用 CSS，不为统一而全部迁移到库。
- Remotion 用于导出作品演示或 45–60 秒个人创作蒙太奇，不作为浏览器运行时依赖。
- 清晨图作为未来蒙太奇的收尾画面。

## 响应式与可访问性

- 桌面端 Hero 文案右置；窄屏重新裁切并提供对比度遮罩。
- Bento 布局按屏宽降为两列和单列，阅读顺序保持《一笔留白》→ 小狼协议 → Python 工具 → 小红书。
- 所有操作均为真实链接或按钮，具备键盘焦点样式。
- 图片提供有意义的 `alt`；纯装饰图使用空 `alt`。
- 主题按钮同步 `aria-label` 与当前状态。
- 动效遵循减弱动画偏好。

## 技术与部署

- 修改范围主要为 `index.html`、`styles.css`、`script.js` 和必要的 `assets/`。
- 不引入 React、Vite、动画库或包管理器。
- 使用现有 GitHub Pages 部署方式。
- 完成后在 `个人网站/网站` 仓库提交并推送 `main`，随后核对公开页面。
